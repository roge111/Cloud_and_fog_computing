## Этап 0: подготовка

У меня вариант на тему I/O. Сделаем скрипт на синхронную запись/чтение мелких блоков по 4 КБ

Для безопасности и удобства создадим тестовую директорию и добавим в переменную окружения

```
TEST_DIR="/tmp/io_bench"
mkdir -p "$TEST_DIR"
```

Теперь сделаем чтение `/dev/zero` и запись `testfile`. Допустим, что это будет циклически 2500 раз в таком порядке:
1. читаем 4 КБ нулей из `/dev/zero`
2. Записываем в testfile
3. из-за `dsync` — ждёт, пока данные реально не окажутся на диске (fsync/fdatasync), и только потом идёт к следующему блоку

```
dd if=/dev/zero of="$TEST_DIR/testfile" bs=4k count=25600 oflag=dsync 2>&1
```

Затем читаем тот же файл и очищаем кэш
```
echo "[2/2] Reading 100MB in 4KB blocks..."
sync
# Попытка очистить page cache 
echo 3 > /proc/sys/vm/drop_caches 2>/dev/null || echo "(drop_caches skipped — no permission)"
```

Затем откроем `testfile` на чтение и на запись `/dev/null` с флагом `O_DIRECT`. `O_DIRECT` — чтение в обход кэширования

```
dd if="$TEST_DIR/testfile" of=/dev/null bs=4k iflag=direct 2>&1
```


В итоге работы скрипта я получил такие цифры:
```
Write (4KB, dsync):  46.1316 s  →  2.3 MB/s
Read  (4KB, direct):  1.7758 s  →  59.0 MB/s
```

## Этап 1: Baseline — Запуск на хосте

Запустим процесс с измерением времени
```
time bash benchmark.sh
```

time — утилита, которая выведет время выполнения и пользовательское с системным временем затраченным. У меня вывод такой:

```
real    0m39,216s
user    0m0,179s
sys     0m2,954s
```

Параллельно, не дожидаясь остановки команды выше, посмотрим статистику работы программы.
```
ps aux | grep -E "dd|benchmark"
```
Я получил несколько строк, но нужная мне выглядит так
```
egor  17189  6.8  0.0  6140  2424 pts/0  D+  19:56  0:01 dd if=/dev/zero of=/tmp/io_bench/testfile bs=4k count=25600 oflag=dsync
```
Что видно отсюда:
- %CPU = 6.8
- %MEM = 0.0
- RSS = 2424 КБ (минимальное потребление RAM)
- STAT = D+ — это состояние означает, что процесс спит в ожидании IO и не может быть прерван сигналом. То есть это подтверждение того, что идет процесс IO-bound.
