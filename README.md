## Этап 0: подготовка

У меня вариант на тему I/O. Сдлеаем скрипт на синхроонную запись/чтение мелких блоков по 4 КБ

Для безопасности и удобства создадим текстовую директорию и добавим в переменную окружения

```
TEST_DIR="/tmp/io_bench"
mkdir -p "$TEST_DIR"
```

Теперь сделаем чтение `/dev/zero` и запись `testfile`. Допустим, что это будет циклически 2500 раз в таком порядке:
1. читаем 4 КБ нулей из `/dev/zero`
2. Заиписвыем в testfile
3. из-за `dsync` — ждёт, пока данные реально не окажутся на диске (fsync/fdatasync), и только потом идёт к следующему блоку

```
dd if=/dev/zero of="$TEST_DIR/testfile" bs=4k count=25600 oflag=dsync 2>&1
```

Затем читаем тот же файл и очищаем кэш
```
echo "[2/2] Reading 100MB in 4KB blocks..."
sync
# Попытка очистить page cache 
echo 3 > /proc/sys/vm/drop_caches 2>/dev/null || echo "(drop_caches skipped — no permission)"
```

Затем откроем `testfile` на чтение и на запись `/div/null` с флагом `O_DIRECT`. `O_DIRECT` - чтение в обход кэширования

```
dd if="$TEST_DIR/testfile" of=/dev/null bs=4k iflag=direct 2>&1
```
